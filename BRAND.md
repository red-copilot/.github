# Red Copilot Brand & Repository Metadata

> Security Engineering for the Agentic Era · 面向智能体时代的安全工程

## Positioning

Red Copilot explores engineering systems for controllable, observable, and verifiable security agents, alongside authorized asset reconnaissance.

**Core message:** From Agent Actions to Verifiable Outcomes.

**核心表达：** 从智能体行动，到可验证的结果。

## Visual system

- **Primary background:** near-black (#0a0a0b)
- **Primary accent:** signal red (#ff3b3b)
- **Secondary text / lines:** zinc gray (#71717a, #52525b)
- **Foreground:** white (#ffffff)
- **Style:** restrained, technical, high-contrast; favor diagrams and evidence over decorative gradients or generic hacker imagery.

## Social preview

The repository social preview is configured separately from README content. Use a **PNG or JPG** image, ideally 1280 × 640, with a short title, one-line positioning statement, and generous safe margins. Do not rely on README SVG banners to set repository social previews.

Recommended headline:
**From Agent Actions to Verifiable Outcomes**

Supporting line:
**Security Engineering for the Agentic Era · 面向智能体时代的安全工程**

Before publishing, export a PNG/JPG and upload it in each repository’s **Settings → General → Social preview** section. Organization avatar is also a separate image setting; use a square PNG/JPG export of assets/red-copilot-mark.svg.

## Repository identity

- **red-copilot:** Red Harness Python Runtime — reproducible agent execution and evaluation.
- **harness:** Red Harness Go SDK — Go-native execution and trust boundary.
- **red-x:** ARL 3.0 — authorized asset reconnaissance and EASM.

Keep the distinction explicit; the Python runtime and Go SDK are separate implementations, not interchangeable packaging of the same runtime.
